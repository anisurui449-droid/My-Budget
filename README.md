# My Budget Android project

Features: CASH IN, CASH OUT, running balance, transaction history, date and note, and local on-device storage.

## Build with Codemagic
1. Upload this project folder to a GitHub repository (keep `codemagic.yaml` at the repository root).
2. Connect that repository in Codemagic.
3. Run the `My Budget Android` workflow.
4. Download the generated debug APK from build artifacts.

This ZIP is the Android source project, not a precompiled APK. The APK is created by the cloud build.
